# Plugin & Rule Reference

This file documents custom and external plugins and notable rules in this repository.

## External Plugins (found in `externalPlugins/`)

- **EX-PO007** — Policy Naming Conventions - type indication
  - Location: externalPlugins/EX-PO007-NamingConventions.js
  - Purpose: Ensures policy names include a type-indicating prefix (for example `AM-` for AssignMessage).
  - Node type: `Policy`
  - Enabled by default: yes
  - Usage: place the file in a directory and run apigeelint with `-x ./externalPlugins` to load it.

- **EX-PO001** — Streaming
  - Location: externalPlugins/EX-PO001-CheckForPoliciesWhileStreaming.js
  - Purpose: Detects `AssignMessage` and `ExtractVariables` policies when request/response streaming is enabled; such policies are not allowed with streaming.
  - Node type: `Bundle`
  - Enabled by default: yes

## Example: using external plugins

```
apigeelint -x ./externalPlugins -e PO007 -s path/to/your/apiproxy -f table.js
```

## Notable local rule: PS-BN001 (Mandatory Policy Attachment)

- File: rules/PS-BN001-MandatoryPolicy.js
- Purpose: Validates that configured mandatory policies are present and attached to the required flow locations.
- Configuration: uses `configProperties.json` under the rule key `PS-BN001`. The expected format for each entry is:

```
Type|PolicyName|ProxyEndpoint:PreFlow:Request
```

Example `configProperties.json` snippet:

```json
"PS-BN001": {
  "enabled": true,
  "config": {
    "mandatoryPoliciesAndFlow": [
      "AssignMessage|AM-MyPolicy|ProxyEndpoint:PreFlow:Request"
    ]
  }
}
```
